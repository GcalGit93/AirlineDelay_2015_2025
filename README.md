# Airline Delay 2015-2025 Data Analytics Project



## PLEASE SEE: \[portfolio post](https://gcalgit93.github.io/gcalgit93/project/2026/05/21/Airline-Delay-Project.html) for more information on the project.



To recreate the files needed for the dashboards and all analysis,



1. Load Airline\_Delay\_Cause.csv into postgresSQL using the PSQL client facility into a staging table (here, StagingAirlineDelay, CreateAirlineDelayStagingTable.sql).
2. Create carrier\_dim, airport\_dim, flight\_date\_dim, delay\_cause\_dim, fact\_flight\_delays, fact\_flights tables and insert data into them from the StagingAirlineDelay table.
3. Save carrier\_dim, airport\_dim, flight\_date\_dim, delay\_cause\_dim, fact\_flight\_delays, fact\_flights tables to CSVs using the PSQL client facility.
